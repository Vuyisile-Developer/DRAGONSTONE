# DragonStone E-Commerce Website for Sustainable Products

## Overview

DragonStone is an eco-friendly e-commerce platform specializing in sustainable home products. The website aims to provide customers with easy access to environmentally conscious products while promoting awareness through features like carbon footprint tracking and a loyalty EcoPoints system.

This project includes both customer-facing and admin portals, built with modern web technologies for a responsive and secure user experience.

---

## Features

- Browse and search sustainable products
- Product details with carbon footprint information
- Shopping cart and secure checkout with multiple payment options (PayPal, Bank Transfer, Cash on Delivery)
- Admin dashboard for managing products, orders, users, and reports
- Role-based access control for admin security
- EcoPoints loyalty system rewarding sustainable choices
- Responsive design for desktop, tablet, and mobile devices
- Carbon footprint calculations and eco-impact reporting
